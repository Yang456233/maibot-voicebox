# 麦麦声匣

为麦麦选择一个声音：轻量的 Edge TTS，或通过独立 IndexTTS 2.5 服务使用自己的角色参考音频。声音、语言和语气按聊天会话绑定，不改变麦麦的人格与记忆。

**版本：0.1.0 开发预发布。** 实机验收进度见 [验证记录](docs/VALIDATION.md)。IndexTTS 实机合成、QQ 播放与人工试听全部通过前，不宣称正式可用，不发布 1.0.0。插件 ID：`github.Yang456233.maibot-voicebox`。

## 可以做什么

- Edge 即用示例“晓晓”，以及两个待导入音频的原创 IndexTTS 配置模板“星奈”“月白”。模板不包含第三方角色声音。
- 标准 WebUI 配置页与聊天命令；试听不改变会话绑定。
- 自动、持续语音、文字三种模式；支持“下次语音”。默认由明确语音请求或 AI 选择触发。
- 原文朗读或中文转日语朗读，日语默认保留中文原文。
- IndexTTS 配置命名情绪预设，由 AI 在当前角色允许的列表内逐条选择；非法选择回退默认语气。Edge 仅提供音色、语速、音调和音量。
- 每次回复一条语音，图片、表情与引用信息保留；原文进入语音描述，由麦麦保存历史。
- 超长、代码、网络失败、资源缺失时保留文字。默认最长 200 字，不截断，不偷偷切换音色。
- 每会话冷却、最多两个并发合成、容量受限的内存缓存、原子保存会话设置。

## 环境与安装

目标兼容范围：MaiBot `1.3.14–1.3.99`，SDK `2.16.0–2.16.99`。接入范围限定 QQ；验收目标为 SnowLuma。其他平台未验证。

1. 下载发布页的源码 ZIP，使用麦麦 WebUI 的“本地 ZIP 安装”，或把仓库内容放入实例的 `plugins/maibot-voicebox/`。
2. 在标准配置页设置管理员 QQ 号；保留默认 Edge 角色即可开始。
3. 在允许测试的私聊中发送 `/声匣 状态`，然后 `/声匣 试听 xiaoxiao`。
4. 想用克隆声音，再按 [IndexTTS 部署指南](docs/INDEXTTS.md) 启动独立服务并导入角色包。

尚无公开 Release 时，可在开发环境运行 `python scripts/package.py` 生成 ZIP。源码根目录必须有 `_manifest.json` 和 `plugin.py`。由宿主安装 manifest 声明的 `edge-tts`、`aiohttp`；**不要在麦麦环境安装 torch、IndexTTS 模型依赖**。

默认配置由 SDK 生成，参考 [config.example.toml](config.example.toml)。配置区包括插件与行为、Edge 服务、IndexTTS 服务、角色、IndexTTS 语气、中日翻译、管理员。角色列表可以重复添加项目，修改后由宿主热更新。Edge 角色仅使用 Edge 字段；IndexTTS 角色仅使用参考音频、时长和语气字段。

## 聊天命令

| 命令 | 功能 |
|---|---|
| `/声匣 帮助`、`/声匣 状态` | 查看帮助、绑定、模式和服务检查结果 |
| `/声匣 角色` | 列出角色和资源就绪状态 |
| `/声匣 切换 <角色 ID 或名称>` | 绑定当前聊天；重名时使用 ID |
| `/声匣 试听 <角色> [语气]` | 朗读统一试听短句，不改变绑定 |
| `/声匣 说 <文本>` | 直接朗读 |
| `/声匣 模式 自动\|持续\|文字` | 更改普通回复的语音策略 |
| `/声匣 下次语音` | 下一次适合朗读的回复尝试语音，失败后消耗这次机会 |
| `/声匣 语言 原文\|日语` | 当前会话的朗读语言 |
| `/声匣 导入 <包名>`、`/声匣 导出 <角色>` | 管理员管理资源包 |
| `/声匣 清缓存` | 管理员清除合成缓存 |

私聊用户只能更改自己的会话。群聊更改角色、模式、语言和“下次语音”仅允许配置管理员；角色导入、导出和清缓存也仅管理员可操作。试听和直接朗读仍受全局并发与会话冷却限制。“文字模式”关闭普通回复语音，不禁止主动执行试听命令。

“自动”模式的明确请求识别覆盖常见的“请用语音回复我”等表达；复杂表述由 AI 判断。否定表达不强制触发。持续模式仍会对过长、代码、不可用服务回退文字。

## 角色与语气

角色包详见 [角色包规范](docs/ROLE_PACKS.md)。导入目录、资源目录、会话状态都位于 SDK 分配的插件数据目录，通常为实例下 `data/plugins/github.Yang456233.maibot-voicebox/`，以宿主配置为准。

导入角色与标准 WebUI 同 ID 时，**导入版本优先**。修改该角色请更新角色包后重新导入；配置热更新不会丢掉已导入资源。角色包更新会清空合成缓存。只有参考音频有效才允许切换到 IndexTTS 模板；“配置就绪”不代表模型服务可连接，需检查 `/声匣 状态`。

首版只内置“日常”默认语气。开心、安慰等配置需自行添加并试听；尚未完成主观试听的预设不会作为推荐声音发布。角色名称只是原创配置标签，不附带任何动漫角色音频。

## 开发与测试

```sh
uv venv --python 3.13
uv pip install -r requirements-dev.txt
.venv/bin/python -m pytest -q
.venv/bin/python scripts/validate_release.py
.venv/bin/python scripts/package.py
```

结构：`plugin.py` 接入 SDK；`voicebox/` 管理角色、状态、翻译与后端；`bridge/` 是独立模型服务；`tests/` 为自动测试。测试使用隔离假模型，不下载权重、不访问 QQ、不发送消息。真实后端和 QQ 验收单独记录，不能以 mock 测试通过替代。

正常回复通过 `ReplyExtension` 转换，由宿主发送和写历史。规划 Hook 仅为 `reply` 工具补充本插件选项；发送观察 Hook 只识别本插件已登记音频，明确失败最多补发一次原文。状态未知不重发。命令反馈、其他插件通知、已有语音不会进入普通回复转换路径。
