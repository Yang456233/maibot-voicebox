# 故障排查

| 现象 | 检查与处理 |
|---|---|
| 角色显示未就绪 | IndexTTS 模板需导入自己的参考音频；相对路径在插件数据目录 assets 内 |
| 角色配置就绪但不能合成 | `/声匣 状态` 检查模型是否加载；角色资源存在与服务可用是两个条件 |
| Edge 不可连接 | 检查网络、代理及音色 ID；在线音色目录可访问仍不保证每次合成都成功 |
| IndexTTS 401 | 插件与服务 token 不一致；不要贴出密钥 |
| IndexTTS 404 | 不是本仓库桥接协议，或资源已清理；检查 URL 和服务版本 |
| IndexTTS 429 | 有界队列已满；文字回复会保留，不自动重发语音 |
| IndexTTS 503 | 模型正在加载、权重缺失或设备不可用；查看服务终端 |
| IndexTTS 504／插件超时 | 当前设备推理超过预算；缩短文本或使用远程服务 |
| 音频解码失败 | 使用标准 PCM WAV；MP3 需在服务端安装 FFmpeg |
| 日语回退中文 | 确认 utils 模型任务可用、翻译结果有效及 Edge 日语音色匹配 |
| 群里无法切换 | 发命令者 QQ 号需列入 `admin.qqs`，QQ群自身管理员身份不会自动授权 |
| “持续”仍出现文字 | 内容太长、代码、冷却、并发已满、缺资源或后端失败，都会保留文字 |
| 语音发送失败 | 检查 SnowLuma 已登录、连接状态及 QQ 音频转换依赖；明确失败最多补发一次原文 |
| 状态未知没有补发 | 为避免重复消息，不在未知投递结果下重发；先看适配器日志 |
| 更新配置后设置保留 | 会话保存在插件数据目录 state.json，与标准配置独立 |
| 配置文件版本不兼容 | 保留备份，按版本升级说明迁移，不删除会话文件来掩盖错误 |

当前只支持 SnowLuma QQ 验收范围。不要把合成 MP3/WAV 成功当作 QQ 实际播放成功。发送后应检查客户端能否播放、图片是否保留、历史是否保存中文原文、有无重复回复。

自动语音以回复动作和当前会话为边界，不转换其他插件通过 send API 发出的通知。长消息 ID 的宿主别名与适配器路由变化需重新联调；当前目标 SnowLuma 使用短数字消息 ID。
