# 麦麦声匣 0.1.0 开发预发布

为麦麦按聊天会话选择角色声音，首版接入 Edge TTS 和独立 IndexTTS 2.5 桥接服务。

## 本版功能

- 标准 WebUI 配置、聊天命令、角色试听、会话绑定与管理员权限。
- 自动／持续／文字模式和“下次语音”，通过 SDK 回复扩展转换当前回复。
- 原文朗读、中文转日语，默认保留中文原文。
- IndexTTS 参考音频及命名情绪预设；Edge 音色、语速、音调和音量。
- 有界合成并发、缓存、冷却、超时、失败文字回退与资源包导入导出。
- 独立桥接部署工具、中文指南、自动测试和 GitHub CI。

## 验证状态

- 本地 55 项自动测试通过；SDK 配置和本机 MaiBot manifest v2 格式校验通过。
- Edge 实际中文合成通过，统一短句约 1.7 秒生成约 5 秒的 MP3。
- IndexTTS 完整模型部署、MPS／CPU 性能、QQ 客户端播放、附件及历史保存仍待实机验收。
- 情绪预设的人工试听尚未完成，开心／安慰示例只用于实验。

这是开发预发布，不代表上述待验收项目已通过。目标兼容范围：MaiBot 1.3.14–1.3.99、SDK 2.16.0–2.16.99；QQ 验收目标为 SnowLuma。

使用源码 ZIP 或 `maibot-voicebox-0.1.0.zip` 在 WebUI 本地安装。IndexTTS 必须独立部署，插件不自动下载模型。包内不包含参考音频、模型权重、服务密钥或聊天记录。安装与配置请参阅 README。
