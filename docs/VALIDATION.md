## 2026-10-27 CI 调度修正

[运行 40359681784](https://github.com/Yang456233/maibot-voicebox/actions/runs/40359681784) 的 Ubuntu Python 3.11／3.13 检查全部通过。两组 macOS 任务没有执行任何测试步骤：GitHub 注明 ARM runner 容量不足，多次分配失败后取消任务。这不是单元测试断言失败。

CI 将 macOS 改为官方标准 `macos-15-intel`，保留 Python 3.11／3.13、全部测试及打包检查，并关闭矩阵 fail-fast，确保一组失败不会取消其他组。云端 macOS 检查覆盖 Intel；Apple Silicon 的本地验证不能等同于云端 ARM 矩阵通过。

## 本机 IndexTTS 接入记录

- 使用用户授权的官方示例 `IndexTeam/IndexTTS-2-Demo/examples/voice_03.wav`；音频只存本机，不随插件包发布。
- 通过真实桥接接口上传参考音频并合成，再以麦麦实际 Python 环境、已保存配置和 `Engine` 调用复验：输出有效的单声道 22050Hz / 16-bit WAV，标准试听句约 3.03 秒音频。
- 本机角色 `index_demo`（IndexTTS 官方示例）设为默认声音；未删除 Edge 角色，也未更改会话语音模式。其他用户安装时仍默认 Edge，不包含本机路径或示例音频。
- 用户级后台服务监听 `127.0.0.1:7861`，首页及 `/v1/health` 可查询状态。启用 `PYTORCH_ENABLE_MPS_FALLBACK=1`；未修改官方模型源码。
- 以上是模型和插件调用链验证；QQ 客户端播放、附件、历史原文与音色主观试听仍需实际聊天验收。

日语原文短句「こんにちは。今日もお疲れさまでした。」通过相同桥接合成：8.633 秒，输出 1.997 秒、22050Hz WAV。此项不包含麦麦 LLM 的中文转日语翻译或主观发音质量验收。
